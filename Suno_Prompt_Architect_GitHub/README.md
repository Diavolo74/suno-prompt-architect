# Suno Prompt Architect

Mini-studio web autonome pour créer des prompts destinés à Suno AI.

## Fonctionnalités

- Sélection et mélange de genres musicaux
- Ambiances, émotions et progression musicale
- Paramètres de voix, interprétation et langue
- Instruments, arrangements et tempo
- Thème, phrases d'inspiration et structure des paroles
- Réglages de production, exclusions, Weirdness et Style Influence
- Génération des champs Style of Music, Lyrics et Exclude Styles
- Copie des prompts et export TXT / JSON

## Utilisation locale

Ouvrir simplement `index.html` dans un navigateur récent (Chrome, Edge, Firefox ou Safari).
Aucune installation ni serveur n'est nécessaire.

## Publication gratuite avec GitHub Pages

1. Créer un compte sur https://github.com si nécessaire.
2. Créer un nouveau dépôt public, par exemple `suno-prompt-architect`.
3. Ajouter à la racine du dépôt les fichiers `index.html`, `.nojekyll` et `README.md` de ce dossier.
4. Dans le dépôt, ouvrir **Settings → Pages**.
5. Dans **Build and deployment**, choisir **Deploy from a branch**.
6. Choisir la branche **main** et le dossier **/(root)**, puis cliquer sur **Save**.
7. Attendre la publication, puis ouvrir l'adresse affichée dans la section Pages.

L'adresse sera généralement de la forme :
`https://TON-PSEUDO.github.io/suno-prompt-architect/`

Le dépôt doit être public si tu utilises GitHub Free. Le site publié est accessible publiquement sur Internet. Ne place aucune information privée dans le dépôt.

## Confidentialité

L'application fonctionne côté navigateur. Les prompts et réglages sont traités localement ; aucun compte Suno ou serveur applicatif n'est requis pour utiliser ce générateur. Les fonctions d'export créent des fichiers sur l'appareil de l'utilisateur.
